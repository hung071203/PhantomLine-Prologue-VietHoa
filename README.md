# 🇻🇳 Phantom Line: Prologue – Bản Việt hóa

Bản Việt hóa **phi lợi nhuận** do người hâm mộ thực hiện cho **Phantom Line: Prologue**, game kinh dị sinh tồn góc nhìn thứ nhất bối cảnh Đông Âu hậu Xô Viết. Trong game, bạn khám phá vùng đất bị **Sương Mù** nuốt chửng, đối mặt các **dị thường không-thời gian**, sinh vật bí ẩn và những bí mật của tập đoàn **Mortfield Industries**.

Bản Việt hóa giúp người chơi Việt hiểu trọn cốt truyện, lời thoại, nhiệm vụ và mô tả vật phẩm mà không cần tra từ điển giữa lúc đang bị truy đuổi trong bóng tối.

## 🛠️ Hướng dẫn cài đặt

### Bước 1: Tải file
Vào mục **[Releases](https://github.com/hung071203/PhantomLine-Prologue-VietHoa/releases/latest)** và tải file **`PhantomLine-VietHoa.exe`**.

### Bước 2: Tắt game
Thoát hẳn game nếu đang mở. Không cần tắt Steam.

### Bước 3: Chạy file cài đặt
Nhấp đúp vào `PhantomLine-VietHoa.exe`.

> ⚠️ **Windows có thể hiện cảnh báo "Windows protected your PC".**
> Lý do là file chưa được ký số (chữ ký số tốn phí hằng năm), **không phải virus**.
> Bấm **More info**, rồi bấm **Run anyway**.

### Bước 4: Kiểm tra thư mục game
Tool **tự động tìm** thư mục game qua Steam. Nếu ô đường dẫn bị trống hoặc báo *"Chưa tìm thấy game"*:
1. Bấm **Chọn...**
2. Trỏ tới thư mục chứa file `PhantomLine.exe`, thường là:
   ```
   C:\Program Files (x86)\Steam\steamapps\common\Phantom Line Prologue
   ```
   hoặc
   ```
   D:\SteamLibrary\steamapps\common\Phantom Line Prologue
   ```
   > 💡 Mẹo: trong Steam, chuột phải vào game, chọn **Manage → Browse local files** để mở đúng thư mục.

### Bước 5: Cài đặt
Bấm **Cài Việt hóa**. Khi thấy thông báo *"Đã cài Việt hóa"*, trạng thái chuyển sang **ĐÃ cài Việt hóa** màu xanh.

### Bước 6: Vào game và chơi 🎮
Mở game như bình thường. Text sẽ hiện tiếng Việt, **dù bạn chọn ngôn ngữ nào trong game**.

---

## 🗑️ Gỡ Việt hóa

1. Tắt game.
2. Chạy lại `PhantomLine-VietHoa.exe`.
3. Bấm **Gỡ Việt hóa**.

Game sẽ trở về nguyên trạng như chưa cài.

**Gỡ thủ công:** vào thư mục `Phantom Line Prologue\PhantomLine\Content\Paks\` và xóa 3 file:
```
PhantomLine_VietHoa_P.pak
PhantomLine_VietHoa_P.utoc
PhantomLine_VietHoa_P.ucas
```

## ❓ Câu hỏi thường gặp

**Cài Việt hóa có bị Steam ban, VAC ban không?**
Không. Bản Việt hóa chỉ thay file text, không can thiệp vào bộ nhớ game, không sửa file `.exe` và không đụng tới cơ chế chơi.

**Có ảnh hưởng tới file save không?**
Không. File save được giữ nguyên, cài hay gỡ Việt hóa bất cứ lúc nào cũng được.

**Có sửa file gốc của game không?**
Không. Tool chỉ **thêm** 3 file mới vào thư mục `Paks`, mọi file gốc giữ nguyên. Nhờ vậy, khi bạn chạy **Verify integrity of game files** trên Steam, bản Việt hóa không bị coi là file lỗi.

**Chơi online với bạn bè không dùng Việt hóa có được không?**
Được. Việt hóa chỉ đổi chữ hiển thị trên máy bạn, không ảnh hưởng tới người chơi khác.

**Game cập nhật thì sao?**
- Đa số trường hợp bản Việt hóa **vẫn chạy bình thường**.
- Câu nào nhà phát triển mới thêm hoặc sửa sẽ hiện **tiếng Anh**, cho tới khi có bản Việt hóa mới.
- Hãy theo dõi mục **Releases** để tải bản cập nhật.
- Nếu sau khi cập nhật game bị lỗi, cứ **Gỡ Việt hóa** rồi chờ bản mới.

**Tôi muốn chơi lại bằng tiếng Anh?**
Bấm **Gỡ Việt hóa**. Đổi ngôn ngữ trong game không có tác dụng, vì bản Việt hóa thay text của mọi ngôn ngữ.

## 📖 Lựa chọn khi dịch

Để giữ không khí của game và tránh rối, một số tên được **giữ nguyên tiếng Anh**:
- **Tên nhân vật:** Oracle, Roman, Boyd, Sumin, Rockwell, Jack, Atlas...
- **Tên địa danh:** Black Forest, Redrooms, Poolrooms, Cape Murkreach...
- **Tên phe phái và tổ chức:** Mortfield Industries, Allied Nations, Eastern Federation...
- **Tên vũ khí và trang bị:** AK-74, M77, 7.62×39, 9mm...
- **Thuật ngữ đồ họa:** DLSS, FSR, TAA, VSync, Lumen...
- **Biển hiệu tiếng Ba Lan** trong game được giữ nguyên để tạo không khí.

Bảng thuật ngữ chính:

| Tiếng Anh | Tiếng Việt |
|---|---|
| Anomaly | Dị thường |
| The Fog | Sương Mù |
| Pocket | Túi không gian |
| Husk | Husk |
| Inventory | Hành trang |
| Stash | Kho đồ |
| Salvage | Tháo dỡ |
| Bleeding | Chảy máu |
| Radiation | Phóng xạ |
| Stamina | Thể lực |
| Teleporter | Máy dịch chuyển |
| Operator | Người điều khiển / Đặc nhiệm |

La bàn dùng ký hiệu tiếng Việt: **B** (Bắc), **N** (Nam), **Đ** (Đông), **T** (Tây). Lưu ý **N là Nam**, không phải North.

## ⚠️ Vấn đề đã biết

- **Hai font pixel thiếu dấu.** Font `PublicPixel` và `PixelOperator`, dùng cho hiệu ứng máy quay VHS, không có dấu tiếng Việt. Ở những chỗ này, chữ có dấu có thể hiện bằng font khác. Giao diện chính, phụ đề và hành trang không bị ảnh hưởng.
- **Một số câu đùa chơi chữ** (ví dụ trò "knock knock") không chuyển ngữ được trọn vẹn, nên đã được dịch sát nghĩa.
- **Một số chuỗi kỹ thuật** dành cho nhà phát triển (tên debug, chữ thử nghiệm) có thể vẫn hiện tiếng Anh. Người chơi bình thường hầu như không gặp.
